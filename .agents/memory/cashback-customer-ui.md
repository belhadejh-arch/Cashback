description: The user's standing visual and navigation requirements for customer-facing CASH BACK screens.

Use the user's attached CASH BACK mobile screen as the canonical reference for customer-facing UI: black/dark surfaces, orange-to-gold accents, rounded cards, Changa, Arabic RTL by default, one consistent text size across the app, and the customer profile/avatar at the top of the home screen. The home layout includes location/search, a cashback promotion, categories, participating shops, recent activity, and a bottom navigation bar. Each major section should open on its own screen; receipt capture and notifications must be full pages. Keep all receipt entry points visually consistent, use a logo-only centered home brand beside the profile/actions row, and label the Arabic wallet “محفظتي”. Keep dark/light and Arabic/English/French preferences applied across the app and persisted to the user's account.

**Why:** The user repeatedly made fidelity to the attached design mandatory and specified profile placement, theme/language behavior, independent receipt/notification pages, consistent camera navigation, and uniform text sizing.

**How to apply:** When changing customer screens, match the reference while retaining live backend data and working controls; do not invent shop ratings, balances, or activity to fill visual gaps. Use Changa and the same text size for all visible copy, route every receipt CTA to the same camera page, and preserve shared camera control styling.
